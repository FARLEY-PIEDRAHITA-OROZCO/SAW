# Introducción

Bienvenido al componente formativo denominado **Metodologías, normas y estándares de seguridad orientada a aplicaciones web**, el cual hace parte del programa de formación técnica en **Seguridad de Aplicaciones Web**.

## ¿Qué aprenderás en esta fase?

| Área | Temas |
|------|-------|
| **Fundamentos** | Vulnerabilidad, amenaza, riesgo, bug, patch, testing, medidas, métricas y KPI |
| **Infraestructura** | Componentes de una aplicación web y su arquitectura técnica |
| **Normatividad** | ISO/IEC 27001, 27002, 25010, ciclos PDCA y SDLC |
| **Metodologías** | OWASP, pruebas pasivas/activas y pentesting |
| **Vulnerabilidades** | OWASP Top 10 y herramientas SAST/DAST/IAST |
| **Resultados** | Checklist, evaluación de riesgos y reportes de pentesting |

## Cómo usar este wiki

- Usa la **búsqueda** (botón de lupa arriba) para encontrar conceptos rápidamente.
- La **barra lateral** agrupa el contenido por fase y por tema.
- Los bloques de **código** ilustran ejemplos técnicos (inyecciones, configuraciones, scripts).
- Los **callouts** resaltan advertencias, peligros y recomendaciones.
