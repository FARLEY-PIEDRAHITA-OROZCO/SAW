# Introducción

El conocimiento y apropiación de las herramientas de las **Tecnologías de la Información y la Comunicación (TIC)** se hace hoy en día indispensable para cualquier ámbito de la sociedad; no solo por la inmersión en la que se está, sino por su constante evolución.

## Qué se desarrollará en este componente

El siguiente video expone de manera genérica la importancia del dominio de estas herramientas, base que se desarrollará en este componente formativo:

| Área | Temas |
|------|-------|
| **Software** | *Software* de sistema, de aplicación y de programación |
| **Internet** | Historia, evolución y servicios de la red |
| **Ofimática** | Procesadores de texto, hojas de cálculo, presentaciones, bases de datos y colaboración |
| **Evaluación** | Reportes, estadísticas e informes para la toma de decisiones |
| **Mejora continua** | Optimización de procesos, mejora del producto y norma ITIL |

::: info Ruta de aprendizaje
El componente propone un recorrido secuencial: se inicia con los fundamentos del *software*, se continúa con el internet y la ofimática, y se cierra con la evaluación de la información y los procesos de mejora continua.
:::
