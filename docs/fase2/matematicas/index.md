# Matemáticas

El componente formativo de **Matemáticas** acompaña la formación técnica aportando las bases numéricas, estadísticas y geométricas necesarias para la comprensión de los conceptos técnicos del programa. Se organiza en **tres niveles**, cada uno con su propia estructura:

## Ruta de estudio

```text
Nivel básico → Nivel intermedio → Nivel medio
```

Cada nivel incluye glosario, material complementario y referencias bibliográficas propias.
