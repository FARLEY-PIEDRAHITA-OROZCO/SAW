# Matemáticas · Nivel medio

Este nivel desarrolla el pensamiento geométrico y algebraico: el cálculo de **áreas y volúmenes**, la **trigonometría**, las **ecuaciones** y el estudio de **funciones**, con énfasis en la función lineal y su aplicación al punto de equilibrio empresarial.
