# Matemáticas · Nivel básico

Este nivel presenta los fundamentos numéricos necesarios para abordar los contenidos del programa: desde los **conjuntos numéricos** hasta las **operaciones aritméticas** en los distintos conjuntos y la **proporcionalidad**, con ejemplos prácticos aplicados a la vida cotidiana.
