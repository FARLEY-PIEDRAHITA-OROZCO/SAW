# Matemáticas · Nivel intermedio

Este nivel aborda el manejo y la interpretación de datos a través de la **estadística descriptiva** y la estandarización de medidas mediante el **sistema de unidades**, herramientas fundamentales para el análisis de la información en el ámbito productivo.
